Dashboard gadget

  1. Save the report. To show it to other people, save it as Everyone who uses FormScope.
  2. Open a Jira dashboard and select Edit, then Add gadget.
  3. Search for FormScope report and add it.
  4. In the gadget settings choose the report, a chart or table view, and how many rows to show. Save.

What viewers see

  • The gadget runs the report for each viewer with that viewer's own permissions. Results are never cached from one viewer for another.
  • It shows when the form data was last refreshed, and warns while indexing is incomplete.
  • Selecting a bar opens the report in FormScope with the matching requests listed.
  • Viewers who can't see the report, can't use FormScope, or whose site has no active subscription see a clear message instead of data.
