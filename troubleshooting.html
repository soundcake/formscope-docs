Troubleshooting

A report says results may be incomplete

A data source is still indexing for the first time. Check progress on the Indexing tab.

A recent form edit is missing

Form edits don't always update the request. They appear at the next daily reconciliation, or a Jira admin can select Refresh now or Full rescan.

"Checking your access to forms"

FormScope confirms your access to each form with Jira the first time you view a report. Later views reuse the result for up to two hours.

Some forms are never indexed

They use view restrictions and Jira refused FormScope access. This is expected; see Permissions.

Someone sees fewer results than I do

Reports apply each viewer's own Jira permissions. Sharing a report doesn't share data.

Jira rejected the JQL

Fix the JQL shown in the message. Remove ORDER BY, and make sure brackets and quotes are balanced.

This report covers too many requests

Add JQL (for example by created date) or filters, or choose fewer forms.

A number total looks wrong

Answers that aren't valid numbers are excluded and counted in the report's notes. Check the unit of each question in the data source.

The CSV download didn't start

Some browsers block downloads from embedded pages. FormScope then offers to copy the CSV instead.

FormScope says the subscription isn't active

Ask a Jira admin to start an evaluation or subscribe in Manage apps.
