Security

  • Runs on Atlassian: FormScope uses only Atlassian-hosted compute and storage. It has no external servers and no outbound connections.
  • Least privilege: it requests only read access to Jira work items and users, plus its own app storage.
  • Permissions enforced on the server: licence, app access, report access and data permissions are checked in Atlassian's backend for every request, using Atlassian's signed context, never browser-supplied identities.
  • Tenant isolation: each Jira site's data lives in its own Forge storage.
  • Safe input handling: report settings are validated strictly, JQL is evaluated by Jira as the viewer, and CSV exports neutralise spreadsheet formulas.
  • No secrets or credentials are stored by FormScope.
  • Redacted logging: logs contain identifiers and error codes, not answers or personal data.
