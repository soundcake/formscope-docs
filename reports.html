Reports and mappings

Report types

TypeUse it to
ChartGroup by up to two fields and count requests or form submissions, or total, average, minimum or maximum a number question. Show it as bars, a line over time, or a table.
TableList one row per form, with answers and Jira fields. Search, sort and page through results.
CompletenessFind submitted forms that are missing answers to the questions you choose.

Templates

Templates help you start: Requests by department and status, Equipment quantities by month and Escalation information completeness. FormScope never assumes what your questions mean. Every template asks you to pick and confirm the questions or mappings to use.

Choosing requests

  • Forms. One or more data sources.
  • Form status. Submitted, locked and open (draft) forms. Charts include submitted and locked forms by default.
  • JQL (optional). Narrows the requests, for example created >= -90d AND status != Done. Jira evaluates it with each viewer's permissions. JQL selects requests; FormScope's own filters then filter the form answers. Form answers are not searchable with Jira's native JQL.
  • Filters. Filter on answers, number and date ranges, Jira fields and form fields.

Counting rules

  • Requests counts each request once, even if it has several forms or several answers.
  • Form submissions counts each form, so a request with two forms counts twice.
  • When you group by a question that allows several answers, a request can appear in several groups. Totals still count it once, and the report says so.
  • Totals and averages use exact decimal arithmetic. Answers that can't be read as numbers are excluded and the report shows how many.
  • Numbers in different units are never added together through a mapping.

Dates

Group by day, ISO week, month, quarter or year. Each chart says which date it uses:

  • Date answers are calendar dates and are not shifted between time zones.
  • Created and Updated are the request's Jira dates, grouped in the report's time zone.
  • Form last updated is when the form was last saved. Native forms do not record a separate submission date, so FormScope doesn't invent one.

Drill down

Select any bar, point or table row to list the requests behind it, then open a request in Jira or export the list.

Question mappings

A mapping combines equivalent questions from different forms into one reporting field. For example, map "Department" in an equipment form, "Business unit" in an access form and "Cost centre" in an order form to a mapping called Department. Then group or filter every form by it in one report.

  • Only Jira admins create mappings, deliberately. FormScope never guesses that questions are equivalent from their labels.
  • A mapping takes at most one question from each form and only compatible answer types.
  • Number mappings need a single unit; questions with different units (for example USD and GBP) can't be combined.
  • Answers keep their original values; only the question is combined.

Form versions

Each form on a request keeps its own copy of the form's design. FormScope reads answers with that copy, so renamed questions, changed choices and questions removed from newer versions keep their original meaning. Questions FormScope tracks by their stable internal identifier, not by label.

Completeness

For each selected question and submitted form, FormScope reports one of: answered, not answered, hidden by form conditions (not counted as missing), not in that form version, or can't be assessed (when FormScope can't reliably tell whether the question applied). Open forms are not assessed.

Saving and sharing

Save a report as Only me or Everyone who uses FormScope. Report names and settings are visible only to the people who can see the report. The owner can edit; Jira admins can also edit and delete shared reports. Sharing a report never shares data: each person sees only what they can access in Jira.

CSV export

Export any table, drill-down or report to CSV (UTF-8 with a byte order mark for spreadsheet compatibility). Exports apply the same permissions and filters as the report, include all matching rows up to 25,000, and never silently cut rows off; larger exports ask you to narrow the report. Text that a spreadsheet could treat as a formula is prefixed so it stays plain text.
