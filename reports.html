Reports and mappings

Report types

TypeUse it to
ChartGroup by up to two fields and count requests or form submissions, or total, average, minimum or maximum a number question. Show it as bars, a line over time, or a table.
TableList one row per form, with answers and Jira fields side by side. Search, sort and page through results.
CompletenessSpot submitted forms that are missing answers to the questions you choose.

Templates

Start in seconds with Requests by department and status, Equipment quantities by month or Escalation information completeness. Each template walks you through picking the questions or mappings to use, so the report fits your forms exactly.

Choosing requests

  • Forms. One or more data sources.
  • Form status. Submitted, locked and open (draft) forms. Charts use submitted and locked forms by default.
  • JQL (optional). Focus on the requests you care about, for example created >= -90d AND status != Done. Jira evaluates it with each viewer's permissions, then FormScope's own filters slice the form answers.
  • Filters. Filter on answers, number and date ranges, Jira fields and form fields.

Counting rules

  • Requests counts each request once, even when it has several forms or several answers.
  • Form submissions counts each form, so a request with two forms counts twice.
  • When you group by a question that allows several answers, a request appears in each matching group, and totals still count it once.
  • Totals and averages use exact decimal arithmetic, and the report tells you how many entries weren't valid numbers.
  • Unit-safe totals: mappings keep units consistent, so USD and GBP answers never mix.

Dates

Group by day, ISO week, month, quarter or year. Each chart names the date it uses:

  • Date answers are calendar dates, exactly as entered.
  • Created and Updated are the request's Jira dates, grouped in the report's time zone.
  • Form last updated is when the form was last saved.

Drill down

Select any bar, point or table row to list the requests behind it, then open a request in Jira or export the list.

Question mappings

A mapping combines matching questions from different forms into one reporting field. Map "Department" in an equipment form, "Business unit" in an access form and "Cost centre" in an order form to a mapping called Department, then group or filter every form by it in one report.

  • Jira admins create mappings, so every combined field means exactly what your team expects.
  • Each mapping takes one question per form and checks the answer types match.
  • Number mappings share one unit, so every total adds up.
  • Answers keep their original values.

Form versions

Each form on a request keeps its own copy of the form's design, and FormScope reads every answer with that copy. Renamed questions, changed choices and questions removed from newer versions keep their original meaning, because FormScope tracks questions by their stable internal identifier.

Completeness

For each selected question and submitted form, FormScope reports answered, not answered, hidden by form conditions (never counted as missing), not in that form version, or not assessable. Missing-information counts only include questions that genuinely applied.

Saving and sharing

Save a report as Only me or Everyone who uses FormScope. The owner edits the report, and Jira admins can edit and delete shared reports too. Everyone gets the same report, built from the requests they can open in Jira.

CSV export

Export any table, drill-down or report to CSV, ready for Excel, Google Sheets and Numbers. Exports carry every matching row, up to 25,000 per file, with the same permissions and filters as the report. Formula-like text is neutralised so files open safely in any spreadsheet.
